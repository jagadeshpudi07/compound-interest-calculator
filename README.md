# Compound Interest Calculator 📈

A modern, highly interactive, and visually stunning Compound Interest Calculator built with Next.js, React, and Tailwind CSS. Watch your investments grow with the power of compound interest, featuring dynamic charts, animated interfaces, and seamless dark/light mode switching.

## ✨ Features

- **Interactive Calculation Dashboard:** Easily input your initial amount, monthly contributions, interest rate, and duration.
- **Dynamic Data Visualization:** Real-time generation of investment growth charts using Recharts.
- **Smooth Animations:** Premium, multi-stage animated introduction sequence and interactive charting.
- **Dark/Light Mode:** Includes an animated, horizontal pill-switch toggle to seamlessly change the application's theme using `next-themes`.
- **Responsive Design:** Fully responsive layout optimized for all screen sizes (mobile, tablet, desktop).
- **Production Ready:** Pre-configured builds and lints successfully with no errors, ready for 1-click deployment on platforms like Vercel or Netlify.

## 💻 Tech Stack

- **Framework:** [Next.js 15](https://nextjs.org/) (App Directory)
- **Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Components:** [Radix UI](https://www.radix-ui.com/) primitives
- **Icons:** [Lucide React](https://lucide.dev/)
- **Charts:** [Recharts](https://recharts.org/)
- **Theme Management:** [next-themes](https://github.com/pacocoursey/next-themes)

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🛠️ Building for Production

To create an optimized production build:

```bash
npm run build
```

This project has been heavily tested to ensure that `npm run build` exits cleanly (`Exit code: 0`), preventing any deployment blockers caused by structural or linking issues.

## 🚢 Deploy on Vercel

The easiest way to deploy this Next.js app is to use the [Vercel Platform](https://vercel.com/new).

1. Push your code to your GitHub repository.
2. Sign in to Vercel and click **Add New** -> **Project**.
3. Import this repository.
4. Vercel will automatically detect the Next.js framework and configure the build settings. Just click **Deploy**!
